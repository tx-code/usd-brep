# AP203e2 首个 profile：B1 盒体与 B2 闭合表面样件设计

版本：P0-E2-B0.1，2026-10-15。状态：**Designed / NotRun**。本文固定数据记录设计、数学真值和单缺陷注入点；未生成 `.step`／`.stp`，未实现生成器、解析器或测试，未运行 EXPRESS／CAD 内核。这里的“最小”指首个闭合盒体切片只用必要角色与已经准入的实体种类，不声称 145 条是所有合法 STEP 表达的最少记录数。方向、向量与平面可通过其它合法共享方式减少记录，本设计保留清晰的来源与 owner 对应。

适用依据为 [AP203e2 首个 profile](ap203e2-planar-profile.md)，固定 N2635 制品与 hash 见该册；共同封套与输入物化契约见[正例总册](ap203e2-sample-design.md)，反例的统一预期见[用例目录](ap203e2-sample-cases.md)。字段／WHERE 依据见[几何闭包](ap203e2-planar-geometry-closure.md)及[产品／context 闭包](ap203e2-planar-context-closure.md)。独立数学源为 [P0 的 B1/B2 真值](p0-planar-cases.md#p0-box-truth)。所有数值均为源毫米；角单位为 radian，当前几何不消费角值。

本册B1/B2分别对应统一目录S203-P04/P05；名称为几何别名，不重复计入样件数。U1英寸及带uncertainty锚的P11/P13由总册另列完整增量，不改变本册B1基准。

## 1. 固定输入包络与记录人口

B1 设计包含共同封套 `#1`—`#12`：单产品链、两个 SI unit complex（毫米、弧度）和一个无 GUUNC 的 3D GRC/GUAC/RC complex。其余 shape 包装固定如下；所有未特别指定的几何／拓扑 `name` 均为空字符串 `''`，不是 `$`。

| ID | 完整叶型与字段设计 | 角色 |
|---|---|---|
| `#9` | `SHAPE_DEFINITION_REPRESENTATION(#8,#20)` | 共同封套的唯一 SDR；`#8` 为唯一 PDS |
| `#20` | `ADVANCED_BREP_SHAPE_REPRESENTATION('body',(#21),#12)` | 唯一具体 representation；无辅助 placement item |
| `#21` | `MANIFOLD_SOLID_BREP('',#22)` | 唯一 material solid 定义 |
| `#22` | `CLOSED_SHELL('',(#507,#517,#527,#537,#547,#557))` | 唯一外壳；SET 的书写顺序不构成空间顺序 |

共同封套不含 category、solid-angle unit、uncertainty、装配和附属管理图。它们在这个固定 AP203e2 profile 中可缺；不能从该事实推广到其它 schema/版次。封套必需字段、完整 schema/OID、Part 21 HEADER 以及调用者质量配置由主册统一固定，不由盒体册另造一套。

|---|---|---:|

### 2.4 6 个独立支撑平面与面

第 f 面块的完整模板为：

```text
#n   = DIRECTION('',N)
#x   = DIRECTION('',X)
#a   = AXIS2_PLACEMENT_3D('',#O,#n,#x)
#s   = PLANE('',#a)
#lp  = EDGE_LOOP('',OE_list)
#bnd = FACE_OUTER_BOUND('',#lp,.T.)
#af  = ADVANCED_FACE('',(#bnd),#s,.T.)
```

6 个面均各有唯一明确 FOB；没有孔。`face.same_sense=bound.orientation=.T.`；direction X 与 N 正交，Y=N×X。源平面定义为 `S_f(u,v)=O+uX+vY`，参数 u/v 为源 PLANE 参数；本源 context 每单位 basis 长度为 1 mm，不把它们声明成 schema 的 length_measure 属性。native 有限 window 的独立验证见 §4。

| native 有效性 | 用 [SMLib 构建审计](p0-smlib-source-audit.md)的来源与 ownership 契约，汇总各 validator 返回值和报告 | native 结构与源 use 映射一致；clamp 求值不能掩盖 window 不包含；AssertValid 不替代源语义检查 |

| 失败／发布 | 构建中每个故障注入点、取消与提交边界、完整 candidate 清理 | 失败／取消无模型；成功只发布完整 owning 快照；这些 controls 当前均 NotRun |

native 可为各 owner 生成独立几何定义，来源仍映射到同一 source LINE/PLANE；source 拓扑共享身份不能因此复制或丢失。六面的 finite window 只是目标表示规范化，必须单独记录与独立验证，不能把它标成源定义修改或修复。

## 5. B2：同一个闭壳的合法 surface-model 对照
