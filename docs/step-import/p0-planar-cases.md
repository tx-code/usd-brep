## 1. 测试专用质量配置 Q-P0-mm-01

这些是为本页中等尺度、简单精确夹具选择的**待验证测试值**，不是生产预设，也不是过去未批准的1μm/5μm方案。测试必须明确传入配置，不读取native默认值或source uncertainty来补齐。

| 字段语义 | 本组测试值 | 判定 |
|---|---|---|
| 定义转换误差上界 | 1e-8 mm | 源精确数值/定义到target的实际表示与运算误差有证据上界 |
| 顶点/边/面一致性上界 | 1e-7 mm | 端点在线、边在面、闭合等独立残差；不因工作tol较大而放宽 |
| 派生UV三维误差上界 | 1e-7 mm | 还须全段覆盖、正确owner/方向/区域；UV数值epsilon不能代替 |
| 显式初始工作tol T0 | BRep及V/E/F均1e-5 mm | 记录实际有效值和传播，不能仅打印传入参数 |
| 工作tol绝对上限 | 1e-4 mm | 构建/UV安装/validator前后均检查 |
| 干净正例全过程tol增长 | 0 mm | 不允许无依据增容差；任何真实增长记录并使本组该条件失败，不能改初始基线 |
| 长度/距离辅助检查 | 1e-7 mm | 适用的独立查询/属性检查 |
| 面积辅助检查 | 1e-6 mm² | 只作辅助；不能单独代替区域与拓扑 |
| 体积辅助检查 | 1e-5 mm³ | 仅material solid；不对开放/表面模型伪造0体积 |
| 修复 | None | 不启用修复动作、位移/焊接或stitch/heal |

source uncertainty可以大于上述独立门槛；本组不设置“源uncertainty必须较小”的额外准入条件，必须保留声明并告警，不能偷偷改成工作tol。若另一个配置设置此准入要求，应另立配置与预期，不能混跑。

精确真值优先用整数、有理数或由它们定义的代数式保存；例如25.4写作127/5、面积88写作整数、距离写作√37/2。oracle计算的舍入区间必须足以证明通过或失败；跨越阈值时Indeterminate，禁止固定点采样或随意round成通过。

目标native对象的实数构造/参数确认为仿射后，可用系数/区间方法核对全段；若物化后的NURBS参数/控制数据发生变化，重新检查其误差界。两个端点数值碰巧接近不证明任意曲线全段正确。

资源测试按已冻结fixture的实际记录数N、字节数B、最大深度D建立N/N-1、B/B-1、D/D-1边界，不预设虚构运行秒数或生产内存档位。fixture尚未生成，N/B/D尚未定；运行前必须固定，不能按被测实现的结果反推。硬超时/进程故障由后续隔离契约验收。

## 2. L1：非单位方向、非[0,1]源参数的直线边

本例是face/edge夹具的辅助真值，不表示首片接受独立线框根。长度单位mm：

```text
P=(1,2,3)，direction_ratios=(3,4,0)，VECTOR.magnitude=2
d=(3/5,4/5,0)
C(t)=(1+6t/5, 2+8t/5, 3)
A=C(2)=(17/5,26/5,3)
B=C(7)=(47/5,66/5,3)
边长=10
target q∈[0,1]，t=2+5q
T(q)=(17/5+6q,26/5+8q,3)
```

必须分别检查：

- EC.same_sense=T，edge_start=A、edge_end=B时源参数为2→7。
- 换成edge_start=B、edge_end=A且same_sense=F，源参数为7→2；target曲线仍从A向B递增，源edge/use映射单独反向。
- direction ratios乘正数不改d；换cm时P和m除10，原t仍是2/7，不乘10。
- 反转LINE方向并协调same_sense/端点关系时，源参数变为负数区间，必须保留对应而不是强改成源[0,1]。
- 源顶点偏离LINE时，不能用两顶点直接造线消掉残差。注入法向偏差1e-6 mm，大于本配置1e-7，即使小于native的相交工作阈值也应严格拒绝。

## 3. F1/F2/F3：旋转平面矩形、孔及非零窗口原点

平面定义为：

```text
O=(3,-2,5)
X=(3/5,4/5,0)，Y=(-4/5,3/5,0)，N=(0,0,1)
S(u,v)=(3+(3u-4v)/5, -2+(4u+3v)/5, 5)
```

下表u/v使用canonical基准1mm。外环按+N的CCW，内环按+N的CW；每个顶点是独立明确的VERTEX_POINT，LINE段共享连接顶点身份。

| 环/顶点 | (u,v) | 世界坐标(mm) |
|---|---|---|
| 外A | (0,0) | (3,-2,5) |
| 外B | (12,0) | (51/5,38/5,5) |
| 外C | (12,8) | (19/5,62/5,5) |
| 外D | (0,8) | (-17/5,14/5,5) |
| 孔E | (2,2) | (13/5,4/5,5) |
| 孔F | (2,4) | (1,2,5) |
| 孔G | (6,4) | (17/5,26/5,5) |
| 孔H | (6,2) | (5,4,5) |

F1仅用A→B→C→D→A；F2再加入E→F→G→H→E。基准face.same_sense=T、bound.orientation=T，正例里的其他组合另按等价构造规则生成。

| 属性 | F1 | F2 |
|---|---|---|
| 面积 | 96 mm² | 88 mm²（96-8） |
| 总边界长度 | 40 mm | 52 mm（外40+孔12） |
| 面积形心世界坐标 | (17/5,26/5,5) | (189/55,297/55,5) |
| V/E/F | 4/4/1 | 8/8/1 |
| source loops / logical face-edge occurrences | 1/4 | 2/8 |
| native EU / FU / LU（未增加规范化拓扑时） | 8/2/2 | 16/2/4 |
| 几何bbox | x∈[-17/5,51/5], y∈[-2,62/5], z=5 | 相同；孔不扩大bbox |
| 形状类型 | 开放表面模型 | 开放表面模型 |
| 材料体积 | 不适用 | 不适用，不用0冒充成功volume查询 |

F2独立分类/距离：

| 查询 | 真值 |
|---|---|
| uv=(10,6)，世界(21/5,48/5,5) | InsideFace |
| uv=(4,3)，世界(3,3,5) | InsideHole / OutsideFace，虽在无限支撑面上 |
| uv=(2,3)，世界(9/5,7/5,5) | OnHoleBoundary |
| uv=(13,1)，世界(10,9,5) | OutsideOuterBoundary |
| (21/5,48/5,8)到F2 | 最近点(21/5,48/5,5)，距离3 |
| (14/5,19/10,8)到F2 | 最近点(16/5,8/5,5)，距离√37/2；不能直接drop进孔内 |

目标有限window在本例至少覆盖[0,12]×[0,8]，其向外数值保护另记录；它不是额外的trim边界。刻意缩到u≤11时必须被独立包含检查抓住，不能让SmPlane求值clamp后返回成功。

oracle方法：平面投影；二维有理数orientation/线段相交/点在多边形；shoelace有向面积及孔扣除；到各有限线段的距离最小值。面积/形心公式与边界分类分别核对；结果边界附近必须给数值界和Boundary/Indeterminate，不靠任意大epsilon。

F3保持F2的全部世界几何，改源平面参数原点为`O'=S(6,4)=(17/5,26/5,5)`，X/Y不变，参数关系`u'=u-6,v'=v-4`。外环window成为[-6,6]×[-4,4]，孔UV相应平移；面积、世界bbox、分类和形心仍同F2。该例专门抓“把SmPlane的O当window左下角”或不保留参数原点的错误。

## 4. S1：非共面的共享边开放面片

两个矩形的所选面路径：

```text
FA: (0,0,0) → (4,0,0) → (4,3,0) → (0,3,0) → 闭合，N=+Z
FB: (4,0,0) → (4,0,2) → (4,3,2) → (4,3,0) → 闭合，N=-X
共享边身份: (4,0,0) ↔ (4,3,0)
```

两面共享同一个EDGE_CURVE及其两个VERTEX_POINT，但各有独立OE/use和UV。FA沿共享边+Y，FB沿-Y。共计6V/7E/2F、两个logical loops、8次logical use；共享边4个native EU，其他边2个，总EU=16。面积18mm²，外部自由边总长度18mm，形状是开放折角sheet，不能给material-solid资格。

此例避免用共面两片掩盖面间参数空间和共享方向错误。把共享边复制成坐标相同但身份不同的两条边不是等价变换；必须保留/诊断其不同拓扑，不能严格导入时焊接。

## 6. U1：可精确重述的单位等价夹具

避免把不能有限十进制表示的inch坐标假装完全相同。U1采用原点盒体，尺寸(25.4,50.8,76.2)mm，可在四种单位下精确重述：

| 源单位 | 到mm因子 | 尺寸原文数值 |
|---|---|---|
| mm | 1 | (25.4,50.8,76.2) |
| cm | 10 | (2.54,5.08,7.62) |
| m | 1000 | (0.0254,0.0508,0.0762) |
| 自定义inch | 127/5 | (1,2,3) |

U1世界真值：面积14193.52mm²、体积98322.384mm³、形心(12.7,25.4,38.1)。source uncertainty可用相同物理值0.000254mm，各单位分别写0.000254、0.0000254、0.000000254、0.00001；Q不随这些源单位变化。

另定义foot=12inch，精确因子1524/5mm；点(1,2,3)foot对应(304.8,609.6,914.4)mm。name改成任意其他label不改变该因子；不得按“inch/foot”字符串代替conversion链。实际factor若换为其他正数，按源定义解释并反映新物理几何，不能用标签“纠错”。

LINE的P、m一并换单位时源t不变；PLANE source参数数值与长度basis配套，canonical UV保持同一个世界点。复杂角单位的实际decimal换算值按源数值保留，不因label='degree'直接覆写为精确π/180。

P12不能简单把同一文件四个bool各翻一遍：必须协调LINE递增方向、EC声明端点、OE列表、bound方向、PLANE基与face sense，保证每个正例有明确且合法的源有向语义。盒体共享EC的相邻use还须与同一全局edge定义一致；“全16组合通过”不自动代表所有闭合壳组合通过。

P22还须有该schema/质量profile的源容差语义依据，不能用它普遍宣称任意不在线顶点合法。已解释且允许的微小残差不是移动源定义的许可：LINE端点取其支撑线上唯一对应参数的几何点，native vertex保留源点，实际gap如实记录。若native不能在此条件下保持定义，记录具体目标限制，不靠修改输入使正例变绿。

P24在已取得AP203e2/AP214e3/AP242e1—e3文件中有optional依据；AP203e1修改副本同字段required，归R18的规则控制，不能临时为e1开启端到端资格。P25/P26只把已核版次差异并入设计；来源等级、适用范围与未证事项见[profile附件](p0-schema-profiles.md)。

## 8. 用例记录与P0退出边界

每个未来case至少保存：ID/fixture版本与源hash、精确schema/载体profile、选根、Q/资源配置、输入变量与变换、独立期望、source/target对应、检查方法/数值界、预期终态/诊断阶段、实际观察及NotRun/Passed/Failed/Indeterminate。

正例端到端通过必须同时满足：必需源内容完整；定义和有向身份保持；区域/shape-role正确；native图安全且报告解释完整；Q与tol账本满足；本请求owner和发布契约满足。任何必需项未测或无法判定都不能报Accepted。

本轮完成的是这些期望的文档化和部分版次原文补核。来源文件已有可固定字节；运行profile的完整规则闭包、实际fixture文本、oracle实现和每个NotRun条目的执行记录仍未完成。原生盒体或旧native回建成功不能换名充当这些用例通过，测试数字也不因此晋升为生产默认。
