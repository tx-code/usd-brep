## 已交付行为

`STEP_IMPORT` 为内部 C++20 模块，沿自研 02→03→04 读取和源检查，形成不含 native 指针的中立计划，
再在独立 context 内构建 SMLib 候选。定义曲线、源顶点和支撑面分别保留，目标 LINE 参数映射为 [0,1]，
源参数、四层方向及源图仍保留。目标 UV 在拓扑构建后安装，逐项核验 SAME member、owner 和 mate。

先验证指针，再执行 LEVEL2/SM_WALK；随后独立核验身份、路径、域、几何定义、最终一致性、UV 和查询。
五个阶段分别观测 BRep、面、顶点与边的实际工作容差。完整候选及必需报告均成立后，才交付模型。
普通失败不交付部分模型，报告超限也会销毁完整候选。

模型为只读 owning snapshot，FaceView 强引用模型和 context。报告独立拥有源、诊断和数据证据，
不保活 native BRep；根结果释放后视图仍可查询，全部 native owner 释放后报告仍可读取。
开放面没有 material volume 资格。`Repair=None`，没有移动源顶点、拟合定义线或自动修复。

入口见 [组件接口与构建](../../source/STEP_IMPORT/README.md)、
