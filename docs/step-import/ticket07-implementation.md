# 07 实施合同：共享边材料盒体

2026-10-16，用户在 06 收束后要求继续，开始 07；基点 `efc4f9c`。08—12 保持 on-hold。
沿 implement/TDD 和 SMLib BRep model 技能执行，仍沿内部 ImportBytes/ImportFile、
只读模型/面视图及真实 CLI 验收；不新增私有测试入口或测试包机制。

将中立计划拆为形体级唯一顶点/边及每面的几何、环和使用。源边只构建一次，
其他面通过 SmBrepConstructor 的 existing-edge 路径复用，不靠缝合、坐标合并或复制后冒充共享。
每面每次使用有独立 UV，存到该面对应 mate pair 的 SAME member，不能用整条边的首个 SAME use 替代。

初个实体范围为经过源检查、可独立证明的精确矩形盒体（允许有理刚体坐标及原点/参数变化）；
按八个角、三组正交边、十二条连边及六个完整外向矩形面判定，不按样件 ID 或固定坐标派发。
显式构建材料 region 与边界两侧 shell，核验实际 owner、外向侧、radial 邻接、闭合与材料 census。
不能将计数、Euler、validator 或 CLOSED_SHELL 名称单独当作实体资格。

P04 的独立真值为 8VP/12EC/6AF、24 次有向使用、面积 2200 mm²、唯一边长总和 240 mm、
材料体积 6000 mm³、形心 (7,7,20)。体积使用完整 Q 的 1e-5 mm³ 样件预算；
继续独立核验每面的定义、一致性、UV、域和容差，并用解析盒体证明及 native 量测交叉对照。
总体形体统计与每面统计分开；面视图可按源身份追踪，整体最近点/内外分类不能误用第一面的查询。

先建立 P04 owning/面积/体积的红绿闭环，再验证共享关系、每面 UV/方向、形心、内外及最近点，
加入源顺序/稀疏 ID、方向/参数及刚体变换控制、错误证据反控、普通失败与清理观察。
N26/N27/N28 保持正确源阶段和因果诊断，不补面、不自动翻壳，不在源前提失败后生成体积。
P05 闭合表面角色仍留 08；开放共享片、一般多面体、截面/切割与一般修复不因本票自动取得资格。

目标体积证据独立读取解析/NURBS 曲面系数，并调用 `CreateOrientedTrimBoundary` 取得量测路径实际使用的
SAME 侧有限边界副本，包含 OPPOSITE 使用反向时的舍入和内核实际添加的临时 gap 段。
调用前后核对原 UV 所有者及系数未变；副本在每面积分结束或失败时由 RAII 释放。
报告的 loop 映射不参与积分计算。

对双线性曲面 `S=O+Uu+Vv+Tuv`，采用 native 的 z 通量
`f=(S_z-c_z)*(Su×Sv)_z`，及 Green 原函数 `P=-∫[vmin,v] f(u,w)dw`。
每个实际仿射 UV 段上的 `P du` 至多四次；三点 Gauss-Legendre 对五次及以下多项式精确，
区间根式节点、权重和运算包围浮点误差，不能将它解释为采样误差猜测。
曲面 Jacobian 的全域正下界还必须超过 native 法向量归一化阈值，以免遗漏 mass integrand 的退化分支。

以实际有限段加逐接点直线补缝构造闭合参考积分。每条补缝分别计入通量绝对上界；
每个可能满足 native `abs(du/dt)<=SM_EFF_ZERO` 跳过条件的原段也分别计入绝对上界。
参考积分扩展这两项的总和，覆盖闭合路径及各接点/原段独立省略的组合，不能只比较全加与全不加两个总数。
有限端点及其直线补缝须处于已验证 window，补缝物理像残差不得超过 consistency 预算。
最终区间同时对照精确源盒体体积和 native API 量测值；证据不足返回 Indeterminate，模型为空。
这些操作不编辑原 UV 或几何、不缝合、不增 tol。

上述数值消费路径已按本地 `SmFace.cpp` 的 `SmODEIsoCurveLengthIFEO`、`SmODEAreaIFEO` 和
`CreateOrientedTrimBoundary`，以及 `SmLine::ReverseParameterization` 逐项核查。
初版仅包围端点和无限直线载体交点，未证明覆盖实际有限边界，已由本算法替代，不计为最终资格。
