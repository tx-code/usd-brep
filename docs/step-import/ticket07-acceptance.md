## 本次交付

从原始 STEP 经自研 02—04 检查、中立计划和真实 SMLib 构建，交付只读 owning 材料盒体。
计划按形体保存唯一源顶点/边，按面保存支撑面、环与有向使用。
源边在 native 只建立一次，第二面走 existing-edge 构造路径，不使用盒体 primitive、不缝合或按坐标合并。
每面各自 mate pair 的 SAME use 拥有 UV，逐项核验 radial 邻接、owner、两侧 shell 和材料 region。

不按样件名称、ID 或固定坐标派发，不将计数、Euler 或 validator 当作充分证明。

`Faces()`/`Face(index)` 为 owning 面视图，各面 `Info()` 保留自身 normal/window；
整体 `Info()` 的 normal/window 对多面形体为空。整体 `Closest()` 查询整个边界，
`ClassifyMaterial()` 分内/外/面/边/顶点；native 工作容差造成的边界候选若无法满足查询 Q，返回 Indeterminate。
开放面仍无材料体积或材料分类资格。报告独立于 native 寿命，必需报告成功后才发布完整模型。

## 体积证据修正与审查

初版用端点及无限直线载体交点形成区间四边形，未证明覆盖内核实际消费的有限 UV 边界。
Spec 审查提出 P1；该证明已替换，初版数值通过不被当作最终资格。

最终算法读取 `CreateOrientedTrimBoundary` 的实际 SAME 侧有限曲线副本，包含反参数舍入和临时 gap 段，
分别包围解析/NURBS 系数，确认原 UV 所有者及几何未变。
采用 native z 通量 `f=(S_z-c_z)*(Su×Sv)_z` 和 `P=-∫[vmin,v]f`；
仿射段上的 `P du` 至多四次，以区间三点 Gauss-Legendre 精确积分，不使用采样误差猜测。
有限段逐接点直线补缝构成闭合参考路径；分别累加每条 gap 和每个可能被 tiny-du 分支跳过的原段的通量绝对上界，
覆盖独立省略，不能靠各段相互抵消放行。全域 Jacobian 下界还排除了 native 法向量归一化退化分支。

原 P04 的补缝通量上界为 2.1316282072803922e-12 mm³。
全三维倾斜控制的补缝、微小 du 省略上界分别为 3.355088740164737e-12、
6.3940435133251029e-13 mm³，最终体积证据上界 2.8558133635669952e-10 mm³，仍在原预算内。
这些操作不修改原 UV/几何或工作容差。临时副本由 RAII 在正常和失败路径释放；报告映射不作为积分输入。
详细数学与本地 native 消费路径见[实施合同](ticket07-implementation.md)。
