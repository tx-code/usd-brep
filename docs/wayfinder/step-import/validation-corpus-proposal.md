# 合成参照、真实模型与能力晋升的验收建议

状态：2026-10-15 讨论材料；四层分批验收、代表性消费资格与正确性红线已由用户确认，正式决定以对应票为准。尚无自研importer或全库导入/修复通过声明。

对应票：[怎样用合成参照和真实模型判定导入正确](tickets/08-validation-corpus.md)。

## 判断什么才算通过

对每个请求按冻结的输入、支持范围、质量配置和检查方法判断：必需依赖完整、源语义与目标几何/拓扑相符、所选质量要求达到、修复授权与预算被遵守、候选完整后发布。运行成功、AssertValid、OCCT成功或截图正确都不能单独作为通过条件。

正式宣称支持的能力必须有正例、反例和等价变换测试，并说明已验证的几何/操作/资源范围。没有证据的场景保持未知，不能把“没有检查出问题”改写成“已证明处处正确”。

## 四层测试及首轮建议规模

| 层 | 建议组成 | 作用 |
|---|---|---|
| 合成契约层 | 每项声明支持的语法、实体、几何/拓扑、单位/装配、修复动作都配正负例与等价变换 | 已知真值，精确定位导入语义与预算错误；不以固定案例总数替代覆盖矩阵 |
| 真实固定回归层 | 先选60个常规文件，兼顾12源目录、三类AP、已见几何/表示及尺寸范围，完整读取、固定SHA | 检查实际导出组合和复杂性；不是目的性样本的总体成功率估计 |
| 真实盲测层 | 另留20个未参与规则设计、修复调参和固定集选择的文件，结果形成后再解盲 | 限制对已知样例调参；一旦用于定位/修复就移入回归集并补新盲测 |
| 大模型资源层 | 首轮8个，覆盖尾部尺寸/实体密度及最大文件，单独进程、明确资源限制 | 检查峰值内存、时间、取消、失败隔离、诊断体积和断点续跑，不与普通几何样本的耗时混算 |

60/20/8是初始编排规模建议，不保证自动覆盖所有几何。某已承诺类型没有真实样本时用明确合成例补齐，并报告真实覆盖缺口。选择与去重只留本机匿名ID/哈希映射，不发布原模型。

实现达到前一层条件后逐层扩大，之后再分批扩至4049个STEP。当前不启动几何长跑。既有179个HEADER和40个实体画像已被用于设计，不应冒充完全未见的盲测集；40个里的6个截断前缀也不能作为“完整模型已验证”。

## 合成契约与反例矩阵

| 范围 | 正例与等价变换 | 必须拒绝或准确分类的反例 |
|---|---|---|
| Part21和源完整性 | 前向引用、多个DATA、复合rational实体、编码、实体ID及记录顺序重排 | 重复ID、悬空必需引用、损坏字符串、漏掉rational constituent、未知必需表示 |
| 单位与放置 | 同形mm/m/cm/inch，实际角度单位等价，合法派生轴、混合context单位 | 缺/矛盾必需单位、双重缩放、奇异轴、错误变换方向 |
| 装配 | 重复/嵌套实例、共享定义、同位置不同occurrence、非对称模型镜像/均匀缩放 | 丢失实例、跨定义修改、装配循环、外部引用、非均匀/剪切拒绝 |
| 精确几何 | 解析面、非有理/有理B样条、裁剪/旋转/拉伸的独立公式与参数对应 | 轴交换、法向奇偶错误、域被裁剪、静默拟合或少一部分曲面 |
| 边界拓扑 | 孔/空腔、共享边、反向use/bound/face、3D/pcurve不同参数的一致定义 | 端点正确但内部偏离、方向错、孔被填、空腔丢失或变实心 |
| 周期/奇异 | 缝的双occurrence、跨缝孔、闭合圆、球极点、锥顶点与vertex-loop | 3D重合就合并UV、周期取补集、删除非零闭合边、伪造极小3D线 |
| 修复与容差 | 每个白名单动作独立注入单缺陷；无缺陷模型不作定义性改动 | 多个等近配对、小特征被吞、源优先表示被覆盖、靠放宽验收成功 |
| 失败与生命周期 | 新建成功/失败反复、输入不变、context顺序与资源对账 | 部分发布、失败复用staging、泄漏、取消后残留模型、配置/结果混代 |

不同AP的正例必须满足所选AP/edition实体语义，不能仅给同一文件换FILE_SCHEMA就声称协议兼容。单位、ID、方向等变形后应保持的量由各用例定义；不能用同一条有缺陷的转换代码生成预期结果。

修复阈值测试采用显式测试配置，注入缺陷按预算内、边界附近、预算外分组；例如相对D的0.5D及2D，并对边界判定考虑测量误差。测试配置的数值不是生产默认。还必须测试多个单步不超但相对原基线超预算、间接tol传播、内核检查涨tol、严格配置达不到、原uncertainty很大以及局部保护界无法建立。

## 正确性参照及冲突裁决

证据按问题选择，不能用一个内核包办：

1. 合成几何的独立解析公式、独立Bernstein/B样条求值、明确的有向边界/实例真值是主要几何与语义参照。
2. 源实体及已解释的优先表示、参数对应和拓扑使用关系用于说明文件定义了什么；原始表示有矛盾时按既定规则拒绝，不由投票选一个。
3. OCCT等独立读取器可交叉核对表示根、单位、实例、曲面/边界、查询与属性；各自的自动修复/容差设置和实际变化必须记录。比较的是同一所选范围，不能一个读全装配、另一个只读最大实体。
4. SMLib ValidatePointers/AssertValid及gap报告用于目标图可消费性，不代替源一致性与固定质量配置。

出现分歧先查单位、范围、表示优先级、参数分支、自动规范化/修复与误差测量，再缩小为合成复现。OCCT失败不能自动证明SMLib正确，反之亦然。确有独立证据可裁定某一参照错误时记录结论；证据不足则`Unresolved`，不计通过、不晋升该争议能力。

源与目标允许经验证的seam/拆面规范化，不能硬要求面/边数量完全相等；应要求来源多对多关系、区域、方向和实例语义对账。面积、体积、包围盒、质心用于辅助，不能让总体误差相抵消掩盖局部丢面/薄壁变化。

采样可发现反例，但不是通用全域最大误差证明。报告区分解析真值、受控误差界/区间检查、自适应采样与普通观察；采用的证据强度必须满足质量配置要求，无法支撑要求则无法判定，不通过。具体测量算法和数值条件是后续原型/验收实现的必备交付，不能仅凭把阈值写进配置就承诺它。

## 下游使用资格

建议不仅验收读入模型，还选择代表性消费路径：

- 受限域内的精确求值、端点/法向/参数对应、最近点等查询。
- 平面截面，验证轮廓、闭合/开放、孔及源定义的对应。
- 对合适的闭合合成实体，在副本上作至少一项平面切割；开放曲面采用适用的受支持裁剪。验证新边界、方向及独立解析预期，原模型不变。

同样的几何用SMLib原生构造作控制，用来区分导入缺陷与已有内核操作限制。若控制也失败，应记录内核限制，不能误报源文件非法；但也不能因此授予该项建模资格。查询/建模资格按已测试操作声明，不承诺全部布尔/圆角等操作。

## 原始导入与修复分开验收

- 每个修复案例都有repair-off结果和repair-on结果，报告原缺陷、动作、最大实际变化、tol阶段变化和新问题。
- 无缺陷模型不应改变定义几何/拓扑或增加工作tol；允许的缓存/标记刷新与真实模型变化分别判断。
- 预算内唯一修复通过全部后验检查才能记为已修复；超预算、歧义配对、无可靠保护界等必须拒绝。
- 重复修复不得出现新的几何/tol漂移；不得每一轮重置基线或改变配置来继续。
- 只增tol而gap未减少的结果必须标容差协调，不能把它计为几何闭隙。

## 能力晋升门槛建议

正式声明某项能力前：其支持矩阵中的全部必过合成正/负/变形用例通过；固定真实集中已判定在声明范围内、源有效且配置可达的用例通过；盲测没有未裁决的错误接纳；大模型在已声明资源范围内按契约成功或按已声明限制准确拒绝。

红线是零个**已知的错误接纳、静默丢必需内容、超预算通过、未声明部分发布**。不通过门槛的能力可以保留为内部/明确标注的实验项，但不能把范围内失败临时改名成“不支持”来提高数字。预期拒绝用例只有按预期拒绝才算测试通过，不算导入成功。

对尚未有独立正确性结论的真实文件使用未知/待裁决，不强造pass/fail真值。暂不指定诸如全库95%成功率；当前目的性样本不足以支撑总体估计，也会混入不支持、源非法及资源范围外案例。

## 统计、版本与可复现性

结果至少区分：测试执行状态、声明支持范围、源合法性结论、strict导入结果、repair结果和独立检查结论。崩溃、超时、取消、资源超限、未测、不支持与源非法不能合并成一个“失败”，也不能从分母悄悄剔除。

每批报告列出发现/选定/实际处理/复用/失败/未测数量，以及每项指标实际检查了多少。零几何测量不得报告“零问题”。每个用例关联source SHA、源码/补丁/二进制SHA、依赖版本、构建参数、质量配置、测量器版本及所选根/实例。

同一配置和原件重复运行应有稳定的语义结论与误差范围，不硬要求内核对象枚举顺序恒定。结果断点续跑只复用来源和全部相关版本/配置匹配的成功证据，失败/未知需重试或显式保留；不能混代后继续报整体通过。

真实模型运行按文件/请求隔离，流式结果、资源有界、可取消；大文件单独预算。确定稳定基线后再逐批扩展到全库，不以无限增大超时/内存限制掩盖失败。

## 已讨论并获确认的政策

1. 采用四层验收，首轮真实集以60固定/20盲测/8大文件为选样目标；覆盖矩阵优先于数量，逐步扩大而非立即全库跑。
2. 目标消费资格包含精确查询、截面及代表性副本切割/裁剪，不用显示或单一有效性判定替代。
3. 采用上述正确性红线与独立裁决规则，证据不足不晋升，先验证遵守配置再定标生产默认，不追求掩盖范围差异的单一成功率。
