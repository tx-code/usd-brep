## Question

首版接受哪些 Part 21 语法、AP 版本和表示根？怎样区分可保留的未知元数据、目标依赖图中不支持的必需实体、文件损坏和资源超限？多 DATA、重复 ID、悬空引用、循环引用、复合实体与字符串编码分别如何处理？

## Resolution comments

2026-10-15 · 经用户四项回答确认，首版范围与严格接受规则如下。

### 文件载体

首版接受自包含 Part 21 文本 `.step/.stp`，处理全部 DATA 段、简单/复合实体、引用和字符串编码。ZIP/STEP-XML、外部文件引用、签名及相应扩展语义先明确报不支持。AP203/AP214/AP242 的协议/版本识别与实际实体支持分别判断，不因识别到 HEADER 就承诺完整 AP。

重复 ID、破损语法及歧义引用归文件错误；前向引用在全体相关记录解析后解析。普通引用图不按“有环就非法”处理，装配等关系按各自语义检查。不以替换字符、默认单位或过滤复合实体 constituent 掩盖无法解释的输入。具体语法符合性与版本/属性表须在实现前的规格中列出。

### 首版目标覆盖

常用解析曲线/曲面与非有理/有理 B 样条、裁剪与 pcurve；精确闭合实体、空腔、开放壳，以及基本装配。包含常用旋转/线性拉伸几何；B 样条变体的展开、周期/退化与方向参数的具体规则由精确 BRep 票确定。按增量实现，以整个首版覆盖清单验收，首个盒体增量不能代表首版完成。

复杂 offset、CSG、纯网格/faceted-only 表示、独立线框/点集、非流形及未列入几何延后。上述内容若成为所选目标的必需依赖，必须明确不支持，不能删面继续。

### 失败范围

默认对本次所选导入请求全成全败。允许用户事先明确选择独立根及其完整依赖，但不允许失败后自动丢件、改选最大实体或把成功的部分零件当完整成功；所选装配的任一必需子零件失败则整个所选装配失败。

### 未知内容

已证明不影响所选几何/装配的附加元数据原样保留，并报告未转换。必需几何、单位、放置、拓扑或装配依赖不支持，或未知内容的角色/影响无法确定时拒绝。不能只因未知实体不被 face 直接引用就认定无影响。

诊断需区分源错误、不支持、构建/验收失败、资源超限/取消；具体结果类型命名归后续接口票。几何验收通过不等于完整 STEP schema 或全部元数据合规。

### 后续接口

参数映射、目标规范化的验证方法、单位/装配路径、修复预算与公共结果接口仍由对应票讨论。本票确定接受范围及失败语义，没有实现或动态通过的声明。
