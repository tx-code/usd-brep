# 首版修复白名单与变化预算建议

状态：2026-10-15 历史讨论材料。局部白名单和局部/累计保护原则已确认；数值表中的1 μm/5 μm候选未采用。后续已确认[显式质量配置与参数化预算](tolerance-budget-contract-proposal.md)，生产默认数值延后定标。正式决定以修复票为准；本材料不证明任何修复已实现。

对应票：[允许修复哪些缺陷以及怎样限制模型变化](tickets/07-repair-budget.md)。

## 基本契约

默认严格导入不修复。用户显式启用修复后，对可安全处理的副本执行白名单动作；只读源证据保留。不是所有失败都能先得到可复制的native BRep：如果native图未可信，应在可验证的中立数据副本上修复并重新构建，不对任意损坏指针图调用healer。

导入参数映射错误必须修转换器；等价的目标表示规范化按既定规则单列；派生UV构建有独立误差预算。修复预算仅允许处理已诊断的源不一致，不能把这三者混为“修复成功”。

每个动作需要自身正负例和独立后验检查，验证通过后才可启用。白名单是拟交付能力，不是现有SMLib healer已能可靠执行的声明。

## 首版候选白名单

| 动作 | 必须满足的条件 | 拒绝情形 |
|---|---|---|
| 局部环次序或使用方向纠正 | 正确连接/方向可由未改动的几何和邻接关系唯一推出，修后区域及孔/空腔语义有独立证据 | 有多个可行区域、只能猜源作者意图或实际是适配器方向错误 |
| 端点位置与裁剪区间校正 | 在已有精确曲线/曲面上有一致解；点移动、区间变化及边界变化在预算内，定义曲线/曲面不重新拟合 | 需移动整条曲线/曲面、引入新边界或选中错误周期分支才能闭合 |
| 重复顶点或等价重复边的合并 | 同一零件内、预期邻接明确、对应唯一，几何等价且不会删除真实边界或小特征；保留来源多对一映射 | 仅因坐标相近就合并、跨零件/实例焊接，或同一周期面上的合法重复使用被去重 |
| 既有边界的受限缝合 | 配对唯一、端点与整段边界一致，原始缺口小于预算，沿源声明的预期连接恢复，不新增面或封口片 | 需要补面、构造缺失边、删除狭缝/薄壁，或将源开放壳自动变成闭合实体 |
| 工作容差协调 | 依据测量及误差上界调整，已有独立几何验收阈值不改变；绝对值、增量和局部保护同时通过 | 单纯加大容差直到AssertValid通过；源实际偏差仍超过几何门槛 |
| 非优先派生参数数据的修复 | 源定义几何和优先表示保持，派生UV的误差、分支与区域都通过独立检查 | 原优先pcurve与3D定义冲突，却把优先pcurve删除重drop冒充同一模型 |

几何上几乎重合不证明顶点/边应合并；实际模型可能包含极小间隙、接触面或不同拓扑身份。只有距离条件而无唯一对应/语义证据时，只报告，不自动修。

首版禁止自动：删小边/小面、删孔/空腔、移除薄壁、补缺面、重建未知相交拓扑、改变定义曲线/曲面的拟合或控制点、平均冲突的3D/pcurve定义、选择性丢弃坏零件。需要这些操作的模型明确未修复或未支持。

## 未采用的历史数值候选（规范长度 mm）

| 指标 | 验证候选值 | 含义 |
|---|---:|---|
| 原始可缝合缺口 `G_abs` | 0.001 mm（1 μm） | 不先把大缺口移动变小再宣称入选；比较修前未改动输入 |
| 最大几何位移 `D_abs` | 0.001 mm（1 μm） | 所有被修复的定义点、端点和区域边界的实际三维变化上限 |
| 工作容差最大增加量 `ΔT_abs` | 0.001 mm（1 μm） | 每个受影响实体及容差传播涉及实体均单独对账 |
| 修后工作容差绝对上限 `T_abs` | 0.005 mm（5 μm） | 不能仅检查增长倍数，原始容差过大的模型也不能通过此preset的相关修复 |
| 局部特征保护比 `α` | 0.01（1%） | 对位移、缺口和修后容差再施加与局部受保护特征有关的上限 |

这些是建议用于第一轮合成/真实受控验证的起点，不是已验证生产默认值。用户可在未来界面显式给出更严格预算；提高预算必须作为新的明确配置记录，不因一次失败自动升级或取文件uncertainty的最大值。

## 局部保护与累计变化

对一个修复涉及的局部范围，设 `L_guard` 为可可靠建立的受保护局部长度尺度，例如需要保持的薄壁厚度、小孔尺度或本不应合并的非邻接边界间距。其定义与测量证据必须记录，不能拿整个模型包围盒或任意最短参数边代替。

示意准入条件为：

```text
原始相关缺口 ≤ min(G_abs, α × L_guard)
任一步及最终相对修前输入的最大三维变化 ≤ min(D_abs, α × L_guard)
0 ≤ T_after ≤ min(T_abs, α × L_guard)
max(0, T_after - T_before) ≤ ΔT_abs
```

所有条件同时满足。源uncertainty不参与提高这些上限。原工作容差已经超过上限时，不能不经证明就调小然后标通过；该保守策略应拒绝相应修复，保留源与诊断。

`L_guard` 不是声称首版已经具备的可靠自动特征识别器。无法建立足够可靠的局部保护界时，先禁用涉及位移、合并或缝合的自动动作，仅报告问题；该能力的验证进入最终验收规格。纯表示重排也不能借“不移点”绕过区域/身份检查。

预算从本次修复前的不可变基线计量，每一步都与该基线比较，不在新建目标对象或下一轮healing时重置。合并、拆分或重新生成ID后仍沿来源映射追溯；例如连续两次各移动0.8 μm，最终偏移1.6 μm就超出1 μm预算。修复中间状态的峰值变化也记录，不能通过末尾回退隐瞒不受控过程。

几何“最大位移”不能只取控制点、顶点或少量固定样点。若动作影响曲线区间或面边界，需检查实际几何和区域；同一端点经过整周期后回到原位置不代表边界没有变化。测量/界估计无法支撑相应保证时，状态为无法判定，不作自动修复通过。具体检查算法和资源预算由验收票确定。

local/world规则：预算在所选检查空间的规范mm中定义；若在实例local空间执行，应按已确认的均匀尺度折算，最终也验收world条件。多个不同尺度实例共享定义时，不能只验收其中最宽松的实例；改一个实例须按已确认政策创建独立结果。

## 拓扑预算

拓扑变化采用动作白名单和语义不变量，不用一个“最多改N个对象”的数值当正确性保证：

- 定义曲面、实际边界或特征删除预算为零；首版补面预算为零。
- 顶点/等价边合并仅在上述唯一对应和局部保护条件下允许，完整保留来源映射及数量。
- 不能改变零件/实例身份或吞掉孔、空腔、薄壁。开放/闭合应符合已解释的源目标：源声明闭合模型的已知小间隙可受限修复，合法开放壳不能自动封闭。
- 目标必要的seam/拆面等属于表示规范化，单列变化账单，仍需区域和方向验证，不能当修复删除预算的例外。
- 动作数、迭代数、超时和内存限额是过程保护，具体数值后续确定。出现无进展、重复修复漂移或身份无法对账时停止，不继续放宽预算。

## 容差协调不是几何闭隙

只增加工作容差并不会使3D缺口变小。允许的容差协调仅在原有独立几何门槛内、为表达测量到的误差而进行；报告必须标明 `ToleranceAdjusted` 与实际gap前后值，不能记作 `GapClosed`。

若源3D曲线和优先pcurve存在超阈值冲突，首版白名单不重新拟合二者或任意选一个覆盖。报告为定义冲突，等待独立的显式修复能力与授权，而不是用容差协调处理。

## 修复接受和拒绝

每个动作在副本上进行，动作后及整轮结束重新检查：

1. 原问题是否按其几何/拓扑定义消除，不能只看操作bool、status或缓存problem flag。
2. 无新问题；单位、源参数、定义曲面、区域/周期分支和关键拓扑保持。
3. 最大缺口、位移、容差增量/绝对值及局部保护均通过；所有受影响对象和传播对象可对账。
4. 表面积、体积、包围盒和关键查询结果作辅助交叉检查，不能用总体数值接近替代局部特征检查。
5. 最终通过前面已定的精确BRep验收；独立验证未通过、未收敛或不支持的结果不发布。

任一步超预算、无法判定、引入新问题或出现native失败，拒绝本次候选并保留原始输入；报告哪些动作尝试过、失败在哪个约束、需要什么后续能力。不能返回混杂了部分修复的模型作为成功结果。若原严格导入本来已合格，原模型可以继续保留，但不能把它标作“修复成功”；具体结果接口由后续票确定。

## 与现有 healer 的关系

已核对当前 `SmHealData.cpp`：`Fix_BadGaps`没有几何闭隙实现，`Fix_BadLoops`调度禁用；现有全序列可能改变容差、退化实体和区域。因此不能直接以 `SM_HO_ALL` 实现本白名单。

每项能力应选择可控入口并验证动作范围；需要补实现或修状态传播时另建有失败复现的实现任务。当前讨论不授权启用禁用阶段或顺便重构整个healer。

## 本轮待确认

1. 首版采用上述局部修复白名单，禁止自动删特征、补面或拟合定义几何；动作需单独验证后启用。
2. 采用1 μm缺口/位移、1 μm容差增量、5 μm修后容差作为保守验证候选，真实定标前不称生产默认。
3. 同时采用局部受保护尺度1%限制和相对原始输入的全流程累计检查；无法可靠测量或超预算则报告并拒绝，不自动放宽。
