# 单位、坐标与装配实例契约建议

状态：2026-10-15 讨论材料；单位政策、本地零件定义与实例保留方式、首版变换范围已由用户确认，具体决策以对应票为准。没有导入器实现或能力通过声明。

对应票：[单位坐标与装配实例的正确性契约是什么](tickets/05-context-assembly.md)。

## 长度、角度与上下文

建议规范长度使用 mm，物理角度使用 rad。原始层保留源单位定义、数值和 context；中立层记录源→规范单位的换算因子，目标适配器另负责 SMLib 的 STEP-style 度值角和 ordinary/NURBS 参数映射。

不能把所有曲线参数、B 样条 knot 和 UV 都统一当长度/角度缩放。每个支持的几何类型必须声明参数的意义和转换：例如圆柱的两个坐标可能分别为角和线性坐标，NURBS knot 不是长度。pcurve 自身参数、pcurve 的 UV 值与曲面参数映射也要分开。

单位按 representation context 解析，不能给整个文件任意选一个全局单位。支持所选范围内的 SI 和 conversion-based 链、显式维度检查；换算因子必须有限、有效且与量纲一致。不能用文件名、unit 名字或导入后的包围盒猜测尺度。

建议必需长度/角单位缺失、冲突、不可解释时严格失败。规范定义的可选字段默认值可按定义采用并记录；这不等于在缺少必需单位时猜 mm。单位覆盖选项若以后需要，必须由用户显式指定，报告 source 与 effective 假设，不能静默覆盖。

对于同一原始几何记录被不同上下文引用，缓存与共享身份必须包含适用语义上下文；不能仅凭实体 ID 复用已缩放的 target 对象。若源上下文本身矛盾或歧义无法消除，应失败而不是复制两份猜测几何。

## 不确定度、工作容差与修复预算

分别保存：

1. 源 `uncertainty_measure_with_unit` 及其单位/上下文；它是文件声明的源精度信息，不是已经测出的每条边最大缺口。
2. 导入几何检查的验收阈值；由我们的契约决定，不能遇到失败就自动提高。
3. SMLib 实体的实际工作容差；构建和检查可能影响它，需要记录前后数值。
4. 修复预算；允许位移、容差增长及拓扑变化的限额，与源 uncertainty 分开。

源 uncertainty 缺失时应标为缺失，数值默认政策由后续容差/修复票决定，不继承一个没有记录的内核默认值就当作源数据。所有长度型精度量同样换算到 mm；面积/体积与尺度按平方/立方换算。均匀缩放后的 world 验收不能还套未缩放的 local 长度阈值。

数字误差与建模精度采用双精度运算并记录可接受数值范围。巨大平移和细小特征的精度预算需专项测试；禁止为了数值方便而悄悄重定位源装配。

## 坐标与放置

几何保留在零件定义的本地坐标，装配节点记录相对父节点的变换，并明确列向量约定、组合顺序及 local/world 空间。

对列向量采用：`p_world = T_parent_world * T_child_parent * p_child`。中立层的长度已经规范化，变换中的平移也必须处于对应的规范长度单位。源关系若把 source child 坐标映射到 source parent 坐标，可用两侧单位变换组合推导规范关系：`T_canonical = U_parent * T_source * inverse(U_child)`。这里的式子只描述已明确源方向的关系，不允许靠关系名称猜转移方向。

单位换算和源显式 scale 分别记录，避免重复乘 1000 或把单位换算当用户几何缩放。

保留源放置及其派生基。`axis2_placement_3d` 应按实体定义的派生规则构造坐标基；原始 axis/ref_direction 不需要先满足直接正交，合法非平行 ref_direction 可能经投影生成基。只有缺失可选轴时按规范默认；零方向、近奇异/无有效基或必需位置不完整须诊断，不能任意“正交化修好”。

不强行改成某个观察方向或 USD 的 up-axis/厘米约定；STEP 导入的规范长度与现有 USD 出口换算是不同接口的事情。

## 零件定义与实例

建议一份零件定义对应一份规范 local 几何/拓扑；多个 occurrence 引用同一定义，分别保留 instance ID、父节点、源关系、local-to-parent 变换。装配定义可以复用，但 occurrence 路径各自独立；按名称或坐标接近不能合并身份。

首版覆盖基本产品/形状关联，并支持两类常用内部表示关系：

- `mapped_item` / `representation_map` 及其变换；
- 基于产品 usage 的父子关系，配合 `context_dependent_shape_representation` / `representation_relationship_with_transformation` / `item_defined_transformation` 等定义的放置。

不能仅按 MAPPED_ITEM 出现就认定它是完整产品装配；必须保留它的实际语义角色，单独识别表示映射与产品 occurrence。两个路径同时描述相同关系时需要对账，不得盲目增加双份零件；矛盾而无法消除时失败。

共享仅针对同一源定义及已解释的一致语义上下文，不在 loader 内做形状相似性去重。所选 assembly 有必需子零件或 placement 不支持，沿用请求全成全败；外部文件引用按已确认首版范围明确不支持。

对于后续建模，建议提供按需取得 occurrence 在指定空间的独立 BRep 的能力。对一个实例的几何修改应明确创建独立结果，不直接修改所有实例共享的定义；具体公开接口由结果票决定。

## 变换接受范围

| 变换 | 首版建议 | 必须验证的条件 |
|---|---|---|
| 平移与旋转 | 接受 | 单位与方向正确，组合/逆变换一致，轴定义有效 |
| 均匀非零缩放 | 接受 | 显式 scale 与单位变换分开，长度/面积/体积及有效容差按比例对应 |
| 镜像及其与均匀缩放的组合 | 接受 | 记录行列式符号，正确处理 face/use 朝向、法向及实体内外；不能修改其他 occurrence 的共享定义 |
| 非均匀缩放、剪切、其他一般仿射 | 延后并明确拒绝 | 不能先存矩阵后将无法精确查询/建模的实例算作支持 |
| 零尺度、非有限值、奇异变换 | 拒绝 | 分类区分源非法与不支持；不得用单位矩阵替代 |

这些是首版目标而非现有 SMLib 调用的可靠性保证。镜像/缩放的 materialization、法向方向及参数化必须经合成测试后才能宣布支持。源类型实际约束可能禁止某些 scale 数值，应先按源 AP/类型验证，再判断目标能力。

需要变换法向时按逆转置及对应朝向语义处理，不能把它当点直接乘平移矩阵。查询落在 local 空间时，距离、容差和面积/体积要恢复到请求的空间；非均匀变换不能沿用单一尺度换算公式，这也是首版拒绝的原因之一。

## 最小验证用例

以下是设计提出的用例，尚未执行：

- 同一盒体用 mm/m/cm/inch 描述，规范长度、体积、端点与面方向一致；另有 rad/degree 角单位的等价几何/trim 例子。
- 一个自包含文件中的两个零件采用不同上下文单位，再通过实例关系组装，检测重复换算与平移尺度错误。
- 多级装配中复用同一零件一百次；检查定义共享、occurrence 数、world 放置和逆变换，不把同位置 occurrence 去重。
- 对非轴对齐、合法非正交 ref_direction 的放置按源派生规则求值；零方向/平行非法轴等反例明确拒绝。
- 对非对称闭合模型做镜像、均匀缩放以及组合，检查端点、表面法向、内外、体积、world 距离和有效容差；仅球体不足以发现轴交换错误。
- 检测非均匀缩放、剪切、奇异、外部引用、单位链循环和矛盾装配关系的拒绝行为。
- 缺失 uncertainty 与极大 source uncertainty 的例子：报告源事实，但不能使任意缺口自动通过或无限扩大修复预算。

## 已讨论并获确认的政策

1. 规范长度 mm、物理角 rad，必需单位缺失/矛盾默认拒绝；source uncertainty、工作容差、验收阈值和修复预算分别记录。
2. 几何留在零件 local 坐标；保留层级和 occurrence 变换/共享定义，按需生成独立建模结果，不默认把所有实例烘焙到 world。
3. 首版目标支持平移/旋转/均匀非零缩放/镜像；非均匀缩放、剪切及外部引用延后，遇到明确拒绝。

这些政策不提前批准未验证的参数映射、具体容差数值、源 uncertainty 缺失时的验收默认值或变换构建实现；后续决策与运行证据仍然必要。
