# 严格接受范围与失败规则建议

状态：2026-10-15 讨论材料；文件载体、首版覆盖原则、失败范围和未知内容政策已由用户确认，具体结论以对应票为准。未实现导入器。

对应票：[哪些文件和实体能够被严格接受](tickets/04-parse-completeness.md)。已确认的约束是 AP203/AP214/AP242 的共同精确 BRep 子集及基本装配；本文把“子集”拆成可决定、可验收的候选范围。

## 文件层候选范围

首版目标为自包含的 Part 21 文本交换文件，识别 AP 家族、原始 schema 字符串和版本标识。识别协议名只决定解释语境，实际接受还取决于实体、属性和目标依赖的支持情况。不同 AP/edition 的差异须逐项核对，不把同名实体视为所有版本语义相同。

- 处理 HEADER、一个或多个 DATA 段、前向引用、简单/复合实体、嵌套列表、枚举/logical、typed values、`$` 与 `*` 的区别、数字和字符串/注释。
- 保留 schema 原文和各段身份；不能只取 `data[0]` 或因版本后缀不认识而静默改当另一版本。
- 字符串应处理 STEP 转义和与声明的文件版本兼容的字符编码。非法编码报位置，不能用替换字符掩盖无法解释的语义。
- 重复实体 ID、破损语法、歧义引用直接报告文件错误。合法的前向引用在解析完成后解析；不得因单次顺序读取暂未遇到目标而报缺引用。
- 普通跨实体引用图不一概禁止循环；根据语义检查应为无环的关系，如装配实例层级，并设置遍历/深度/资源保护。
- 外部文件解析、ANCHOR/REFERENCE 等扩展语义、签名处理、ZIP/STEP-XML 首版建议明确不支持；若输入使用这些能力，不得悄悄跳过并称完整支持。后续可以单独加入有测试的支持。

Part 21 版本与 AP 版本是两个维度。参考：[STEP Tools Part 21 数据集说明](https://www.steptools.com/docs/roselib/read_write.html)、[Part 21 edition 3 说明](https://downloads.steptools.com/stds/step/)。上述文字是产品范围建议，不是完整 Part 21 合规声明。

## 目标首版的几何与表示范围

以下为首版完成时的候选接受范围，不要求第一个实现增量一次全部做完；盒体增量不能直接当作整个首版已完成。最终逐实体属性/约束表及参数策略仍由后续精确 BRep 票补齐。

| 类别 | 候选承诺 |
|---|---|
| 精确实体 | `ADVANCED_BREP_SHAPE_REPRESENTATION` 下的 manifold solid，含闭合壳及带空腔实体；不得因真实样本暂未见空腔表示就默认删掉内部壳 |
| 开放形状 | `MANIFOLD_SURFACE_SHAPE_REPRESENTATION` / `SHELL_BASED_SURFACE_MODEL` 下的开放壳；保持开放类型，不自动封口 |
| 拓扑 | `VERTEX_POINT`、`EDGE_CURVE`、`ORIENTED_EDGE`、`EDGE_LOOP`、`VERTEX_LOOP`、face bound/outer bound、face、oriented face/shell、solid；准确保留共享与方向 |
| 曲线 | 直线、圆、椭圆，支持范围内的非有理/有理 B 样条，以及裁剪曲线；B 样条的 Bezier/uniform/quasi-uniform 变体需明示展开规则和验证 |
| 曲面 | 平面、圆柱、圆锥、球、环面、非有理/有理 B 样条，常用旋转面与线性拉伸面；源实体的必需生成曲线也须受支持 |
| 曲面边界 | `PCURVE`、`SURFACE_CURVE`、`SEAM_CURVE`、源优先表示、两侧 pcurve、周期缝、闭合非退化边与极点情形；具体映射不能直接复用 Truck 的拓扑限制 |
| 上下文 | 坐标放置、SI/转换制单位、长度/角单位上下文和 uncertainty；单位解释属于几何正确性的一部分 |
| 基本装配 | 零件定义/产品关联、实例、层级及放置；具体 mapped-item 与 relationship 路径、镜像/缩放及外部引用规则由单位/装配票确定 |

首版建议延后：tessellated/faceted-only 表示、CSG 表达式、非流形表示、独立线框/点集、复杂 offset/swept 表示、双曲线/抛物线等未列入的几何、完整 PMI/GD&T 与外部文档装配。某个暂缓实体是所选目标的必需依赖时必须拒绝，不能去掉相关面。

模型库完整样本已有裁剪曲线、有理复合 B 样条、旋转面和开放壳；大文件前缀另见椭圆、线性拉伸面和 quasi-uniform 类型。以上证明存在真实需求，不证明它们已支持。装配、极点和空腔仍须专门合成夹具。

## 严格导入的失败范围

建议以“本次明确请求的导入范围”为事务：默认请求整个文件的目标产品/形状集合，任一必需目标失败就不发布本次可建模结果。报告应保留已完成阶段和诊断；不得把临时生成的部分模型包装成完整成功。

如果用户在转换前明确选择某个独立根，可以单独导入它及全部必需依赖。不能在失败后自动改选“最大的实体”或跳过缺件的装配。根选择方式、模型返回与显式部分结果接口留给结果接口票；本票建议首版不提供自动部分导入。

同一零件只有五张面成功时失败；装配的某个必需子零件失败时整个所选装配失败。源头明确是开放壳，则可以作为开放壳通过，不能按闭合实体误判。

## 未知内容与诊断

建议按作用分类，而非“遇到未知词全部拒绝”或“所有未知实体都跳过”：

| 情形 | 建议结果 |
|---|---|
| 所选目标必需几何、单位、放置、拓扑、装配依赖未知或不支持 | `Unsupported`，附源实体、引用链和不支持能力 |
| 定义缺失、非法属性、装配循环或必需引用悬空 | `InvalidSource`，附位置与依赖链 |
| 已知角色、可证明不影响所选几何与装配的未支持颜色/样式/附加元数据 | 保留原始内容，记录“元数据未转换”，不因此改变已接受模型 |
| 未知内容的角色或影响无法确定 | 保守判为 `Unsupported`；不能仅凭“没有从 face 直接引用”就认定无影响 |
| 构建失败、目标结构或几何检查未通过 | 构建/验收阶段失败；不笼统归咎于源 STEP 错误 |
| 资源超限或取消 | 单独状态，不能计为模型无效或实体不支持 |

这些是结果类别的语义建议，不预选稳定 C/Python 枚举名称。几何导入通过也不代表完整 STEP schema 合规、PMI 或全部元数据支持。

## 最小接受/拒绝例子

- 纯解析盒体、开放带孔面、共享边圆柱、周期球/圆锥顶点、有理曲面和两次实例：各按其明确语义验收。
- 一个装配含两个零件，其中一个必需曲面不支持：整体所选装配失败，不能交付另一零件冒充成功。
- 盒体带首版未转换的已知颜色属性：几何可通过，诊断标明颜色保留但未转换。
- 源根有未知表示、源单位链无法解释、复合实体漏掉 rational 部分、前向引用最终未解析：明确失败，不能用默认 mm、非有理替代或过滤实体来继续。

## 已提交并获确认的范围原则

1. 接受范围采用上述“自包含文本 Part 21 + 常用精确 BRep/开放壳/参数曲线/基本装配”的首版目标，分增量实现，不承诺全部 AP。
2. 默认对所选请求全成全败，不自动保留部分模型作为成功；显式选根可独立验收。
3. 已证明不影响目标语义的附加元数据原样保留并诊断；必需或影响不明的未知内容拒绝。

4. 首版以自包含 Part 21 文本为载体；多个 DATA 段、复合实体、引用与字符串编码纳入，ZIP/STEP-XML、外部引用、签名扩展延后。
