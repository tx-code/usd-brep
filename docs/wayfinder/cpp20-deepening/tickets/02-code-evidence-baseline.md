## Question

为后续取舍准备可核查的仓库证据：哪些固定描述、模板前提、尺寸关系和配置事实仍在运行期建立，
哪些已经有编译期保障？给候选登记具体错误实例、拥有事实的模块、主要消费者、现有验证入口和未知项。

这是 AFK 准备任务，不替用户选方案，也不实施重构。保留已有有效实践，
不把所有 constexpr 声明都计为编译期执行，不把注释中的类型约定当作已证明的存储安全条件。

## Blocked by

无。代码事实盘点可与收益原则讨论独立开展。

## Context

[初步代码线索](../initial-scan.md) 是起点，不能据此宣称全仓盘点完成。
调查覆盖核心几何 SDK 与 STEP；跳过生成产物、二进制夹具和 vendored 上游。
新增信息保存为独立证据材料并从本票链接。
