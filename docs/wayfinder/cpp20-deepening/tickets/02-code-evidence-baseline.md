## Question

哪些已经有编译期保障？给候选登记具体错误实例、拥有事实的模块、主要消费者、现有验证入口和未知项。

这是 AFK 准备任务，不替用户选方案，也不实施重构。保留已有有效实践，
不把所有 constexpr 声明都计为编译期执行，不把注释中的类型约定当作已证明的存储安全条件。
