# Native business failure results

The private construction result and public import outcome are separate seams.
`step_import_business_failure_*_contracts` calls the real qualified planar builder
to require returned business errors, without catching them in the importer first.
Its public synthetic source is qualified through the normal source/semantic/planar
stages. This does not add an admitted import profile or a public test-only hook.

Controls cover unsupported native rounding before work, a deliberately tiny
definition budget after native pointer/LEVEL2 validation, and contradictory
selected-use evidence in a disposable construction plan. The last control changes
neither immutable source nor native defining geometry: the builder must refuse the
correspondence rather than publish it. Errors retain status, key, message, record
and stage; late refusal retains computed observations and discards the candidate.
Numerical formulas, parameter domains and production quality defaults are unchanged.

General construction refuses a surface-model source at its material-solid boundary,
and exact length scaling refuses a nominal angle root. The errors identify the
source shape/unit and retain their original category. Exact curve/surface definition
comparisons include both identical operands and different defining coefficients;
a returned mismatch cannot become equality or suppress the remaining repair checks.
Duplicated disposable planar evidence must not establish a two-polygon shared-sheet
certificate: planning returns its original scope refusal without changing source.

The strict orientation attempt returns a private error variant holding either the
ordinary failure or its owning native witness. Repair consumes that evidence without
throwing it. A separate control uses a real qualified candidate and a weak observer
to establish release before an ordinary failure can reach report delivery; this tests
ownership, not eligibility for geometric repair. Public repair controls independently
exercise the actual native witness, proof exhaustion, exact post-repair definition
comparison, original-attempt diagnostics, cancellation and complete publication.

Public lifecycle controls independently cover cancellation, complete mandatory
reports and atomic publication. Compare complete reports against a frozen baseline
for planar solids/sheets, source units, native-call boundaries and general imports;
compare deterministic nested reports/progress without normalization. Run matching
Release/Debug native configurations. Use focused ownership/resource controls rather
than repeating every expensive per-shape Debug sweep after shared cleanup is covered.

Isolated runtime mutants should remove proof/correspondence guards, throw a returned
business error again, or bypass returned-error cleanup. Unchanged controls must
pass; each mutant must compile and then fail a contract assertion. A compile error
or unrelated crash is not a runtime detection. Raw receipts and mutated copies stay
under ignored local directories.

This does not remove public configuration/query exception contracts or primitive
numerical uncertainty/capacity sentinels. Those must retain their own classification;
allocation failures must not become configured budget errors.
