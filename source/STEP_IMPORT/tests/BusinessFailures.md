# Native business failure results

The private construction result and public import outcome are separate seams.
`step_import_business_failure_*_contracts` calls the real qualified planar builder
to require returned business errors, without catching them in the importer first.
Its public synthetic source is qualified through the normal source/semantic/planar
stages. This does not add an admitted import profile or a public test-only hook.

Controls cover unsupported native rounding before work, a deliberately tiny
definition budget after native pointer/LEVEL2 validation, and contradictory
selected-use evidence in a disposable construction plan. The last control changes
neither immutable source nor native defining geometry: the builder must refuse the
correspondence rather than publish it. Errors retain status, key, message, record
and stage; late refusal retains computed observations and discards the candidate.
Numerical formulas, parameter domains and production quality defaults are unchanged.

General construction refuses a surface-model source at its material-solid boundary,
and exact length scaling refuses a nominal angle root. The errors identify the
source shape/unit and retain their original category. Exact curve/surface definition
comparisons include both identical operands and different defining coefficients;
a returned mismatch cannot become equality or suppress the remaining repair checks.
Duplicated disposable planar evidence must not establish a two-polygon shared-sheet
certificate: planning returns its original scope refusal without changing source.

The strict orientation attempt returns a private error variant holding either the
ordinary failure or its owning native witness. Repair consumes that evidence without
throwing it. A separate control uses a real qualified candidate and a weak observer
to establish release before an ordinary failure can reach report delivery; this tests
ownership, not eligibility for geometric repair. Public repair controls independently
exercise the actual native witness, proof exhaustion, exact post-repair definition
comparison, original-attempt diagnostics, cancellation and complete publication.

Public lifecycle controls independently cover cancellation, complete mandatory
reports and atomic publication. Compare complete reports against a frozen baseline
for planar solids/sheets, source units, native-call boundaries and general imports;
compare deterministic nested reports/progress without normalization. Run matching
Release/Debug native configurations. Use focused ownership/resource controls rather
than repeating every expensive per-shape Debug sweep after shared cleanup is covered.

Isolated runtime mutants should remove proof/correspondence guards, throw a returned
business error again, or bypass returned-error cleanup. Unchanged controls must
pass; each mutant must compile and then fail a contract assertion. A compile error
or unrelated crash is not a runtime detection. Raw receipts and mutated copies stay
under ignored local directories.

This does not remove public configuration/query exception contracts or primitive
numerical uncertainty/capacity sentinels. Those must retain their own classification;
allocation failures must not become configured budget errors.

## Final trim measurement results

`step_import_trim_result_contracts` fixes the returned local-error protocol for
parameter-domain refusals and a real straight-edge/offset-UV paired measurement.
Invalid, reversed, collapsed and nonfinite requested intervals return the original
`FinalTrimParameterDomain` reason without fabricating samples. Existing general
controls retain parameter-roundoff allowances and independently detect a physically
displaced or reparameterized final UV curve.

The local `TrimMeasurementError` vocabulary is separate from execution `Failure`.
The derived-UV boundary retains an unestablished candidate for local parameter
refusal before native work, while a real callback refusal returns its unchanged
cancelled execution error. Neither changes source geometry or quality budgets.
General construction maps a local error to the same former importer diagnostic,
including the original empty record and default stage. Remaining runtime-error
catches preserve only the legacy native-exception fallback contract; returned errors
are never thrown again.

Isolated runtime mutants bypass parameter-error propagation, reclassify its reason,
erase the physical displacement, throw a returned error, or downgrade cancellation
to an unestablished candidate. Require successful compilation, the intended runtime
failure and passing unchanged controls in matching Release/Debug configurations.

## Native status results

The `native` business-failure mode qualifies the public P0 planar fixture first,
then contradicts only a disposable edge plan so the real line factory refuses a
zero direction with `SM_ERR_INVALID_INPUT`. The private builder must return the
former importer diagnostic (`BuildFailure`, `NativeReturnOrConstructionFailure`,
`NativeReturnFailure:1007`, no source record, D5), retaining 17 native calls and
discarding its incomplete BRep. Pointer/deep validation has not run: its optional
observations remain absent, not zero-report successes. No edge/loop report rows
are invented. A separate general-status control retains its distinct
`GeneralNativeReturn:1007` message, and success remains successful.

The required planar line/plane coefficient and envelope readers propagate errors
to the builder. Their numerical refusals retain the former domain-error outcome,
and primitive bounded-arithmetic sentinels keep their separate outer contract.
Public query/archive methods retain direct raw-status exception checks; they do
not turn an internal expected error back into an exception.

Runtime mutants should ignore a returned native failure, erase the discard
receipt, conflate native status with a configured quota, lose the message origin,
or throw the returned status error again. Keep the unchanged real-builder control
and require compilation plus the intended runtime failure for each mutation.

The separate `strict_native` control uses the admitted synthetic B-spline support
and the existing strict-build callback boundary to exercise a real native refusal,
a real trim-domain refusal and cooperative cancellation. This tests report delivery,
not geometric repair eligibility. Operation aborts preserve the pre-migration
unfinished strict observation: they do not add status, diagnostics or a discard
receipt at the coordinator. A private `ConstructionOperation` kind distinguishes
that exit from ordinary contract/execution failure; the cancellation control must
still retain its completed strict-failure observation. None of the controls may
enter the repaired build or charge a face edit.

Compare complete serialized reports with frozen pre-migration native/trim/cancel
controls. Mutants should erase the operation kind, record the unfinished attempt
as a completed failure, or bypass observation for every failure (which must break
the cancellation control). Keep the existing orientation-witness, repair-budget
and complete-import report comparisons in both native configurations.

## General frame results

The `frame` control qualifies synthetic sources with finite, mathematically nonzero
direction ratios whose binary64 normalization is unestablished. It exercises real
material lines, conic reference/axis directions, near-parallel frame projection,
surface placement, independent wireframe/supporting curves and supporting frames.
The private builder returns the original `Indeterminate` / `GeneralDegenerateFrame`
diagnostic, empty record and D5 stage. Charged work and completed validations remain;
checks that have not run retain absent observations. Public import retains the
original bytes and refuses atomic publication. The native range and normalization
formula are unchanged; this is not direction repair or source invalidity evidence.

A real strict build on the same source retains its unfinished original-attempt
report without starting repair, charging edits or manufacturing diagnostics. This
tests the actual construction-to-repair boundary without substituting a callback.
Successful controls retain normalization of finite direction magnitudes and the
STEP defaults for unset axes. Existing geometry, parameter, seam and pole contracts
continue to cover successful uses of returned frames.

Compare complete failure reports against frozen pre-migration outputs, including
the strict attempt. Runtime mutants should reclassify the numerical refusal, throw
it again, erase its operation kind, bypass normalization or substitute a default
basis for unestablished projection. Require successful compilation, intended
assertion failures and unchanged passing controls in both native configurations.
Primitive interval sentinels remain a separate migration. Scalar/coordinate
conversion has the additional controls below; the importer is not exception-free.

## Scalar and coordinate results

The `scalar` control uses real qualified synthetic source inputs at the existing
private builder and public import seams. It covers binary64 overflow/underflow,
coordinate scaling overflow, insufficient coordinate/direction dimensions, line
magnitude, conic radius, curve/surface knots, rational curve weights, independent
points, trim parameters and supporting-frame origins. Parsing failure must not
become zero, clamping, coordinate padding, a quota error or a source-invalid claim.
Normal signed/exponent lexemes retain their original source bytes and geometry.

Each refusal retains the old `Indeterminate` key/message/empty record/D5 and the
native work already charged. Early refusals invent no native work or validation;
late associated-geometry failures retain the completed validators and release
the unpublished model. Strict attempts retain their unfinished report without
starting repair or adding completed failure observations. Complete serialized
reports are compared with a frozen baseline, including first/second-member
collection/document refusals and strict attempts.

The existing assembly placement evaluator separately fixes its old scalar/triple/
scaled-coordinate diagnostic message, placement record and stage. Those used to
pass through its domain-error adapter; normalization errors already returned a
different message. Private `SourceValueConversion` provenance preserves the
distinction without parsing diagnostic text or throwing an error value again.
Existing placement/instance coordinate oracles, context ownership and every
cancellation boundary remain in that contract.

Runtime mutants should change error classification, throw a returned conversion
refusal, fabricate a missing coordinate, replace unestablished physical coordinates,
erase strict-attempt provenance or lose the assembly diagnostic distinction.
Each must compile and fail the intended assertion, with passing unchanged controls
in both native configurations. Receipts and mutated copies stay local.
