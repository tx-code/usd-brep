The fixed AP214 source profiles bind ordinary `SURFACE_CURVE`, `PCURVE`,
`DEFINITIONAL_REPRESENTATION`, `AXIS1_PLACEMENT` and `SURFACE_OF_REVOLUTION`,
including their swept-surface ancestor. They retain original master selection,
ordered associations, parameter curves, units and generator/axis references.
Necessary local and scoped dimension predicates and finite-definition evidence
run before source qualification; source success does not grant native conversion.

## Scope

[Source prerequisite contract](../source/STEP_SEMANTICS/README.md).

## Integrator action

Rebuild STEP semantics and native consumers together. AP214 type population
reports include the appended declarations; previous type identities remain
stable. Keep source checks separate from geometric consistency and native
pcurve, revolution and general surface-model capabilities.

## Compatibility

AP203 catalogs and existing native shape capabilities remain unchanged.
New source reports qualify scoped dimension evidence separately from the full
global-rule suite. The general native builder now classifies its existing
surface-model scope refusal as `Unsupported`, preserving the diagnostic key
and source role; it never promotes a surface model into material. C++ public
layouts, source bytes, quality budgets, repair policy and native archive format
are unchanged.
