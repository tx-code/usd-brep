Native STEP source checking preserves ordinary composite curves in the four
general source catalogs, including ordered/repeated segment references,
direction, transition declarations, original parameters and units. Required
bounded-parent, transition and inverse-use checks run with fixed-source
responsibility; mixed trimmed/composite cycles fail a separate project
dependency prerequisite. Shared graph checks are iterative and budgeted.

This adds source prerequisites, not native composite construction or numerical
continuity evidence. Unsupported required composites still fail before native
calls and publish no partial model; original P0, units and repair policies stay
unchanged.

## Scope

[STEP source semantics](../source/STEP_SEMANTICS/README.md).

## Integrator action

Rebuild the semantic library and its linked consumers.

## Compatibility

Existing C++ interfaces and source byte preservation are unchanged. General
source catalogs gain declarations and dependency checks; P0 stays unchanged.
Source success does not grant native composite geometry, continuous error
evidence or full schema conformance.
