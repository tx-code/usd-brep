Explicit STEP definition selection can isolate proven unselected AP214 FACE.WR2
failures while retaining original bytes, diagnostics, complete declaration
inventory and locality evidence. All other source prerequisites, ownership,
inverse checks and selected native validation remain mandatory. The complete
selected request returns AcceptedWithSourceIsolation (CLI 13) when isolation is
actually applied. Viewer worker adoption binds the scope and budgets, and HUD
distinguishes selection and isolated errors.

## Scope

[Selected-source isolation contract](../source/STEP_IMPORT/README.md).

## Integrator action

Rebuild STEP libraries, native consumers and the viewer worker together. Handle
the new acceptance status and CLI exit code. Request the original-SHA-bound
selection, named isolation profile and positive budgets explicitly; retain owning
source evidence with native exports.

## Compatibility

Internal C++ source/native layouts and result enums expand. Selected source
documents expose qualified selected Part views plus complete original inventory;
ordinary documents remain complete. SourceSnapshot adds an immutable capture hash.
Default source/report paths, repair permissions, geometry budgets, kernel ABI and
native archive format are unchanged. This profile does not add generic source
recovery, arbitrary bad-record exclusion, assemblies or partial selected publication.
