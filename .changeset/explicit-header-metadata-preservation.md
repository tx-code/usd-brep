Applications can explicitly preserve an unset FILE_NAME authorization field
without inventing a string or changing the original STEP. The owning source
retains the original header error and byte/path evidence. Native use requires
general nongeometric interoperability and reports AcceptedUnderInterpretation;
the viewer verifies the same-source mandatory receipt before scene adoption.
Strict defaults, every other header check and all geometric budgets remain intact.

## Scope

[Source header metadata](../source/STEP_SOURCE/README.md) and
[native import](../source/STEP_IMPORT/README.md).

## Integrator action

Rebuild matching source, semantic, native libraries and consumers. Select
PreserveUnsetAuthorization or the explicit CLI/viewer flag only when this
nongeometric exception is intended.

## Compatibility

Source inspection entry points add a defaulted policy argument. InspectOutcome
and native Options append C++ fields; binary consumers require matching rebuilds.
Reports conditionally add header_metadata_preservation. Existing strict report
bytes, kernel ABI, native-file format and default repair selection are unchanged.
