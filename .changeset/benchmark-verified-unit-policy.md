The native STEP benchmark probe accepts the importer's existing explicit verified
unit-dimension interpretation. Measurements retain the requested policy and actual
source-owned interpretation, so interpreted imports can be profiled without
changing their acceptance settings. Other readers reject this native-only option.

## Scope

[STEP benchmark controls](../tools/step_import_benchmark/README.md).

## Integrator action

Rebuild the benchmark probe executables together.

## Compatibility

The optional CLI flag and conditional result fields are additive. Existing default
output and all importer, geometry, source and quality contracts remain unchanged.
