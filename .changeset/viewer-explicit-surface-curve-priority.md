The standalone viewer transports an explicit original/use-bound three-dimensional
surface-curve priority request. It verifies the complete native report before
decoding display meshes, retains original conflicts and conditional qualification,
and refuses incomplete or mismatched results without replacing the current scene.

## Scope

[Standalone viewer input and quality scope](../tools/smlib_viewer/README.md#input-and-quality-scope).

## Integrator action

Deploy matching Python viewer modules and `step_view_export`. Supply the original
SHA-256, complete source-use list and explicit use budget for one STEP file;
directory scans and incompatible repair/normalization plans are refused.

## Compatibility

Existing default requests and v1-v7 scene payloads retain their behavior. Requested
interpretations add a bounded scene marker and require the existing complete
native import report; older workers cannot satisfy the new request. The C++ SDK
interpretation policy, geometry budgets, ownership and public ABI are unchanged.
