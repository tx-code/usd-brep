labels with unavailable encoding and original diagnostics. AP214's name-dependent
purpose restrictions no longer block these legacy labels in this explicit mode.
Known reserved spellings retain the original strict profile refusal as a diagnostic.

## Scope

[STEP semantics](../source/STEP_SEMANTICS/README.md), fixed modified N916 subset.

## Integrator action

Rebuild STEP consumers together. Select general nongeometric interoperability;
unavailable raw DATA text additionally requires opaque string preservation.

## Compatibility

Strict/P0 and other schema profiles retain previous behavior. Geometry, units,
repair policy, quality budgets and publication gates do not change. No kernel
ABI or native archive format changes; full schema conformance is not established.
