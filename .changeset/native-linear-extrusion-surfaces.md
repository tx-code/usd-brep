The fixed AP214 native development path retains linear-extrusion surfaces with
ordinary or positive rational B-spline generators. Construction uses an unfitted
tensor net, preserving generator knot parameters and the scalar extrusion
parameter, including the source vector magnitude and length-unit conversion.
Finite charts cover complete boundary control enclosures and generator axial
variation; definition, parameter, weight and working-tolerance checks still apply.

Source B-spline pcurves use the same surface factory. Source roles, complete
publication, cancellation and explicit execution budgets retain their contracts.
Unsupported generators, unresolved periodic topology, zero-rank constructions and
subsequent geometry/UV failures remain unaccepted. This does not grant full source
schema conformance or continuous original-source conversion qualification.

## Scope

[Native linear-extrusion construction](../source/STEP_IMPORT/README.md#b-样条生成曲线的线性拉伸).

## Integrator action

Rebuild matching STEP libraries and native consumers together.

## Compatibility

The AP214 catalogs append one type and the swept-surface exclusive group while
retaining prior identities; AP203 catalogs remain unchanged. Native reports add
linear-extrusion chart correspondence for the applicable requests. Public C++
signatures, kernel ABI, native-file format, physical budgets and default repair
selection are unchanged.
