Native STEP import adds explicit whole material-collection entry points and the
--material-collection CLI option. Each source solid retains an independent BRep,
body identity, owning queries and modeling copies. All members share one source,
request budget and final publication decision. Native archives preserve the
ordered BRep array without a Boolean union.

## Scope

[Material collection contract](../source/STEP_IMPORT/README.md#material-collections).

## Integrator action

Rebuild STEP consumers. Use CollectionOutcome/MaterialCollectionSnapshot for
multi-body requests and recognize the collection/root-referenced body report
formats. Select compact reporting explicitly when desired. Native archive loads
need their own validation and do not inherit STEP import qualification.

## Compatibility

Existing single-body APIs and reports retain their behavior. Collection support
is explicit, uses unchanged geometric budgets, and publishes no partial result.
Surface models, assemblies and associated geometry beyond the documented collection
scope remain unsupported. The viewer collection path is pending.
