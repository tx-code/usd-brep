The MBx AP214 source subset can retain foreign N2635 REAL representation items
as explicitly permitted property metadata. It preserves the original scalar,
field origin, narrowed REAL type and strict type diagnostic after proving
selected-part attachment and physical-dependency exclusion.

## Scope

[STEP source semantics](../source/STEP_SEMANTICS/README.md).

## Integrator action

Select general-BRep scope and nongeometric interoperability explicitly. Rebuild
affected STEP libraries and their static consumers. Read `derivedSlot` to
identify transmitted derived markers: `redeclaredBy` can also name an explicit
field-narrowing subtype whose slot still contains a value.

## Compatibility

Public C++ layouts remain unchanged. Nine diagnostic descriptors are appended
only to the MBx catalog; original IDs and the other catalogs are retained.
Strict admission, units, geometry, quality, ownership and publication are
unchanged. Borrowed transport does not establish AP214 or OID conformance.
